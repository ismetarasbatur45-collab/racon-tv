RACON TV — TÜRKÇE KURULUM

Bu proje GitHub Pages gibi ücretsiz statik barındırma hizmetlerinde yayınlanabilen bir web sitesi prototipidir. HTML dosyası tek başına değildir; üç ayrı dosya kullanır: index.html, style.css ve app.js.

GITHUB'A YÜKLEME
1. GitHub'da racon-tv deponu aç.
2. Add file (Dosya ekle) > Upload files (Dosyaları yükle) seç.
3. Bu ZIP dosyasını bilgisayarına indirip önce ZIP'ten çıkar.
4. Çıkan klasörün içindeki index.html, style.css, app.js ve README-TURKCE.txt dosyalarını yükleme alanına bırak. ZIP dosyasının kendisini yükleme.
5. Commit changes (Değişiklikleri kaydet) düğmesine bas.
6. Depoda Settings (Ayarlar) > Pages bölümüne gir.
7. Build and deployment altında Deploy from a branch seç. Dal main, klasör /(root) olsun ve Save'e bas.
8. Birkaç dakika sonra adres genellikle https://GITHUB-KULLANICI-ADIN.github.io/racon-tv/ biçiminde olur.
